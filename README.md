Описание функциональности.
Регистрация и вход. Пользователь регистрируется с логином, паролем, ФИО, отделом и ролью (сотрудник или бухгалтер). После входа сессия хранит id и роль; без входа главная страница недоступна.

Сотрудник. Создаёт заявку на справку: тип (2-НДФЛ, о месте работы и стаже, о среднем заработке, произвольная с названием), число экземпляров, причина.
Видит список своих заявок со статусом и датой. Если уже есть активная заявка (подана или в работе) того же типа — показывается предупреждение; можно отправить повторно с подтверждением.

Бухгалтер. Видит очередь всех заявок; можно скрыть готовые и отклонённые. По клику открываются детали: сотрудник, вид справки, экземпляры, причина, статус. Может менять статус по правилам: подана -> в работе или отклонена; в работе -> готова или отклонена; готовые и отклонённые менять нельзя. Каждая смена статуса и создание заявки записываются в историю в бд.

API. REST для заявок и списков сотрудника; доступ по сессии (сотрудник видит только свои заявки, бухгалтер — очередь и смену статуса). В режиме Development доступен Swagger.
